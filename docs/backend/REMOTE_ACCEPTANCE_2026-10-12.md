# Совместная ручная проверка через Tailscale — 12.10.2026

## Условия

Два участника на разных Windows-компьютерах и в разных местах
подключались к одному Java backend через Tailscale Serve:

HTTPS → http://127.0.0.1:8090.

Оба использовали реальный режим клиента и отдельные аккаунты.
Клиенты запускались через desktop/run.ps1.

Результаты ниже основаны на сообщениях участников ручной проверки.
Это не отчёт автоматического тестового запуска.

## Границы проверки

- Автоматические тесты и CI не входят в результаты этого ручного прогона.
- HTTP/WebSocket-трассировки и SQL-проверки к этому отчёту не приложены.
- Отдельные сценарии перезапуска backend, физического сна Windows,
  повторов запросов с Idempotency-Key и конфликтов ревизий
  этим удалённым прогоном не подтверждаются.
- Запуск выполнялся через run.ps1. Установка и запуск приложения
  из Windows-установщика требуют отдельной проверки.
