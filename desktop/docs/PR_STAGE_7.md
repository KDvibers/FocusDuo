## Заголовок

Восстановление соединения и безопасные повторы FocusDuo Desktop

## Описание

Клиент автоматически восстанавливает соединение после сетевого разрыва и заново синхронизирует серверное состояние после перерыва в работе ПК. При неизвестном результате команды пользователь может повторить сохранённый запрос с прежним ключом, не создавая второе действие.

- Автоматический reconnect с backoff/jitter и синхронизация REST + свежий WS перед разблокировкой изменений.
- Heartbeat по двум часам и сигналы восстановления окна; старые соединения, `401`/`4401`, logout и CLOSED обрабатываются по жизненному циклу сессии.
- Явный повтор сохраняет исходные method/path/body/Idempotency-Key/revision; конфликт сохраняет черновик и требует осознанного нового действия.
- Проверено настоящее Compose-окно в демо и через `RealRepository` с локальным HTTP/WS-стендом: сетевые состояния, формы, история, размеры 1280×800/1000×700 и системная рамка. Сохранены 27 реальных скриншотов.
- Обновлены README, ROADMAP и HANDOFF; изменения только desktop/**.

## Коммит и push

Выполнить в PowerShell последовательно, останавливаясь при ошибке:

```powershell
Set-Location "C:\Users\user\Desktop\focusDuo"
git add -- desktop
git diff --cached --stat
git commit -m "test(desktop): verify recovery and Compose interface"
git push -u origin feat/desktop-mvp
```

Это завершающий коммит проверки после сохранённой пользователем промежуточной реализации `0fb2b56`. Описание PR охватывает весь этап 7. Команды передаются пользователю; агент не выполняет commit, push или merge.
