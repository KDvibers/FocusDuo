# PR: Windows MSI FocusDuo

## Заголовок

Добавить Windows MSI FocusDuo со встроенным Java runtime

## Описание

Добавляет упаковку desktop-клиента FocusDuo `0.1.0` в MSI для Windows x64: собственную иконку приложения, ярлыки рабочего стола/«Пуск», установку текущему пользователю и встроенный Java runtime. Сервер выбирается в существующем UI; backend/PostgreSQL поставляются отдельно, личный Tailscale-домен в пакет не включается.

Изменения ограничены `desktop/**`: Gradle-конфигурация native distributions, воспроизводимые ресурсы, инструменты упаковки и инструкции передачи. Пароль и bearer-токен остаются в памяти; несекретные preferences сохраняются при удалении.

## Проверки

- Новый полный прогон: **199 тестов, 0 failures/errors/skips**, 35 s; следующий `check` PASS, runtime-license guard сверил 66 artifacts. Образ и настоящий MSI собраны native Windows x64 / Corretto 21.0.6 / WiX 3.11.2.
- Установка обычному пользователю PASS. Оба ярлыка запускали установленный EXE без JAVA_HOME/PATH JDK; реальные `jvm.dll` и Skiko DLL загружены из установленного каталога.
- URL/username сохраняются в изолированных несекретных preferences; после перезапуска пароль пустой. Установленное явное демо проверено в 1280×800 и 1000×700: перенос длинной русской задачи, прокрутка, системный maximize, иконка/кириллица.
- Удаление через Windows Installer CLI PASS: приложение/runtime/оба ярлыка/регистрация отсутствовали, preferences сохранены. Повторная установка того же MSI PASS: одна запись продукта `0.1.0`, два ярлыка без дублей. Клиент оставлен установленным пользователю, все QA-окна закрыты, исходное пользовательское Java-окно и preferences сохранены.

[Фактический протокол](WINDOWS_PACKAGING.md), [машинные доказательства и SHA-256 15 реальных снимков](evidence/windows-package-2026-10-12.json). Исторический ручной Tailscale-прогон через `run.ps1` не выдаётся за проверку нового MSI.

## Ограничения и передача

Бинарник `FocusDuo-0.1.0.msi` остаётся локальным: **91317919 байт**, SHA-256 `8C47303CA6D871F994CC7248C86D39C728EF69D88ABE99AAC660DC5284E4B987`, **NotSigned**. EXE не заявляется, публикация/Release/commit/push автоматически не выполняются.

Полная приёмка ещё открыта: настоящий HTTPS/WSS/auth, create/join/двусторонние задачи/FOCUS-итог и восстановление комнаты после входа должны быть проверены в установленных клиентах вместе со вторым физическим ПК. Ошибка недоступного сервера в установленном клиенте, чистая VM без отдельного JDK, удаление кнопкой Параметров Windows и обновление между версиями не подтверждены. Самостоятельный запуск на машине разработчика со встроенным runtime не подменяет чистую VM.
