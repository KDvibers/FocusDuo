# Описание

После объединения Windows-упаковки README продолжал описывать установщик как будущую работу. Обновлены запуск готового клиента, инструкция подключения и сводки backend; исходное задание упаковки обозначено как историческое.

Добавлен `WINDOWS_PACKAGE_ACCEPTANCE.md`: точный MSI 0.1.0 получен и сверен по размеру/SHA-256/подписи на втором Windows-ПК, установка завершилась с exit 0. Оба ярлыка открыли установленный EXE со встроенным runtime при пустом JAVA_HOME и PATH без JDK; сохранённые адрес/username и пустой пароль подтверждены. Приложение оставлено установленным для совместного прогона.

HTTPS/WSS из двух установленных клиентов, восстановление комнаты после входа, ошибка недоступного сервера и удаление через Параметры Windows на втором ПК ещё не проверены. Чистая Windows и обновление на другую версию также не заявляются выполненными. Локальные результаты Kotlin-разработчика отделены от новых наблюдений.

Изменения только в README и backend-документации. Код desktop/backend и контракт не меняются. Maven/Gradle-тесты повторно не запускались; MSI не публикуется.

Проверки документации: 204 локальные ссылки/якоря в 9 Markdown-файлах, разбор 10 PowerShell-примеров без их выполнения, локальный Markdown-предпросмотр README с 9 загруженными изображениями и `git diff --check` — PASS. Новый раздел запуска просмотрен визуально; Mermaid в локальном предпросмотре оставлен исходным текстом, рендер GitHub отдельно не проверялся.
