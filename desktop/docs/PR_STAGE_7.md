# PR этапа 7

## Заголовок

Восстановление соединения и безопасные повторы FocusDuo Desktop

## Описание

Клиент автоматически восстанавливает соединение после сетевого разрыва и заново синхронизирует серверное состояние после перерыва в работе ПК. При неизвестном результате команды пользователь может повторить сохранённый запрос с прежним ключом, не создавая второе действие.

- Автоматический reconnect с ограниченной экспоненциальной задержкой и jitter; перед разблокировкой изменений выполняются REST-восстановление и ожидание свежего полного WS-снимка.
- Heartbeat по календарным и монотонным часам, сигналы фокуса и восстановления системного окна с отсечением коротких переключений. Таймер ожидает серверное завершение.
- Pending-команда сохраняет исходные method/path/body, Idempotency-Key и X-Room-Revision в памяти. Повтор выполняется явно; новые действия блокируются до разрешения неизвестного исхода.
- Конфликт применяет актуальный snapshot и сохраняет черновик для осознанного нового действия. Нет автоматической замены ключа/revision при конфликте.
- `401`/`4401`, logout, смена сервера и CLOSED останавливают восстановление; старые соединения не откатывают состояние.
- STAGE7_COMPOSE_RESULT.
- Обновлены README, ROADMAP и HANDOFF. Изменения ограничены desktop/**.

## Коммит и push

Выполнить в PowerShell последовательно, останавливаясь при ошибке:

```powershell
Set-Location "C:\Users\user\Desktop\focusDuo"
git add -- desktop
git diff --cached --stat
git commit -m "feat(desktop): recover connections and retry commands safely"
git push -u origin feat/desktop-mvp
```

Команды передаются пользователю. Агент не выполняет commit, push или merge.
