# PR: живая авторизация Kotlin и Java

Ветка `feat/backend-auth-integration` → `main`, база `7acb617` после desktop PR #8. Push выполняет владелец; удалённые операции не выполнялись. Это контрольная точка backend-этапа 3, а не завершение всей приёмки клиента.

## Заголовок

Проверить Kotlin-авторизацию на Java backend и добавить сценарий восстановления комнаты

## Описание

После появления `RealRepository` проверена совместная работа настоящего Ktor/CIO с Java backend и PostgreSQL. Добавлен отдельный opt-in harness: два Kotlin repository читают заполненную комнату, корректно обрабатывают отзыв токена и восстанавливают участие после нового входа. Это дополняет существующий desktop `backendAuthSmoke`, который проверяет авторизацию с пустой текущей комнатой.

Harness находится в `backend/scripts/kotlin-auth-smoke/`; внешний Gradle init script использует существующие desktop-компилятор и зависимости, пишет результат в `backend/target`. Подготовка комнаты выполняется вспомогательными HTTP-запросами. После проверки закрываются собственная комната и сессии, в том числе при потере ответа успешного create. Секреты не выводятся; выбранный сервер должен быть тестовым, поскольку V1 не удаляет аккаунты.

Обновлены HANDOFF, реестр приёмки, roadmap и команды запуска. Production-код backend, `desktop/**`, общий контракт и fixtures не изменены. Подтверждённых несовместимостей авторизации не найдено.

- Все 10 desktop-копий fixtures совпадают с общими по SHA-256; 17 fixture-тестов входят в 112.
- Новый harness: normal run `BUILD SUCCESSFUL`, exit 0; заполненная комната, неправильный пароль, дубликат username, внешний отзыв → 401/EXPIRED, login/recovery, logout/SIGNED_OUT, независимость второй сессии.
- Намеренный обрыв ответа после реального commit create: ожидаемый exit 1; восстановительная очистка закрыла комнату. В изолированной БД осталось 0 открытых комнат, активных членств и неотозванных сессий.
- Java JAR запущен в WSL на 8090 с новой PostgreSQL 17.11 на 55435. Тестовые процессы/контейнер удалены; пользовательские БД на 5434 и `.env` сохранены.
