## Границы выпуска

Выпуск содержит Windows-клиент. Java runtime включён, но **backend и PostgreSQL работают отдельно**; общий публичный сервер этим релизом не предоставляется. Для совместной работы оба клиента указывают один доступный backend. Для знакомства без сервера есть явный деморежим.

Публикация не меняет объём [проверок установщика и пользовательской приёмки](WINDOWS_PACKAGE_ACCEPTANCE.md). Maven/Gradle-тесты и установленный клиент при публикации не перезапускались. В release notes сохранены ограничения и отсутствие цифровой подписи. Внутренний адрес Tailscale, `.env`, пароли, токены и пользовательские настройки в assets не включены.
