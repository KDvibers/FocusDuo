## Описание для PR

Корневой README теперь описывает FocusDuo как приложение: назначение, возможности, реальные скриншоты, первый совместный сценарий, стек, архитектура и запуск из исходников. Добавлены SVG-логотип на основе существующего интерфейса, инструкция подключения к общему backend и диагностика HTTPS/WSS через Tailscale.

Выделен следующий этап Windows-упаковки для Kotlin-разработчика: реальный MSI/EXE, встроенный runtime, иконка, ярлыки и проверка установки/запуска/удаления. Актуализированы сводки интеграции после принятого PR #21; исторические версии и границы прежних проверок сохранены.

Проверки:

- Проверены локальные ссылки, якоря и пути изображений в изменённой документации.
- 10 примеров PowerShell прошли синтаксический разбор без выполнения команд.
- README отрисован локально через GFM-парсер и Chromium: заголовки, таблицы и все 9 изображений загрузились; просмотрены скриншоты предпросмотра. Mermaid в локальном предпросмотре оставлен исходным блоком; GitHub-рендер диаграммы отдельно не проверен.
- SVG разобран XML-парсером; `git diff --check` прошёл.
- Независимый обзор сверил возможности, команды запуска и ограничения с исходниками и отчётами.

Maven/Gradle и живые HTTP/WS-сценарии в этом PR не перезапускались: изменения касаются документации и SVG. Backend CI после push должен сработать из-за изменения `backend/README.md`; новый результат CI здесь не заявляется.

Установщик этим PR не создаётся и не публикуется. Его реализация и фактическая приёмка — следующий отдельный PR Kotlin-разработчика по [WINDOWS_PACKAGING_HANDOFF.md](WINDOWS_PACKAGING_HANDOFF.md). `desktop/**`, backend-код и общий контракт не изменены.
